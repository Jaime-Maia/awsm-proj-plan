# Changelog

## v1.0.0: primeira versão pública

- Skill para planejar projetos com várias entregas ou uma rotina de gestão.
- Exploração de caminhos possíveis antes das perguntas guiadas, em rodadas de até três.
- Tarefas verificáveis por entrega, com no máximo 10 tarefas por plano.
- Sugestão de skills e connectors por etapa, conferindo o que está disponível na sessão.
- Verificação da documentação existente antes de criar algo novo, com um único local para tudo.
- Variações por tipo de projeto, incluindo software com versionamento vX.X.X e rotina pessoal.
- Não depende de outras skills para o questionamento.
- Resposta no idioma dos últimos chats do usuário.
- README em inglês e licença MIT.
